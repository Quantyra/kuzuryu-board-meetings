# Roadmap

This roadmap describes likely directions, not guaranteed delivery dates.

## Near Term

- Improve test coverage for Slack API edge cases and git publishing.
- Add release-time container pull verification after GHCR package visibility is
  confirmed public.
- Add examples for common hosting platforms.
- Add configurable minutes retention and redaction guidance.

## Medium Term

- Add a web status page for active meetings.
- Add optional persistent storage beyond the in-process store.
- Add richer audit export formats.
- Add typed API examples for automation clients.

## Non-Goals

- Replacing Slack workspace administration.
- Storing Slack or git credentials in the application database.
- Providing legal advice about board governance, quorum, or records retention.
