# Support

Kuzuryu Board Meetings is open source software provided under AGPL-3.0-or-later.

## Community Support

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Feature requests.
- Questions about local or cloud setup.

## Security Issues

Use the process in `SECURITY.md` for suspected vulnerabilities. Do not disclose
security-sensitive details in public issues.

## Operational Responsibility

Operators are responsible for:

- Slack app configuration.
- HTTPS ingress.
- Secret management.
- Git credentials for minutes publishing.
- Data retention and compliance obligations for meeting records.
